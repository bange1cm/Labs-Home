# Labs@Home — Capstone Project by Cora Yerke

This capstone project focuses on the design and development of a desktop application intended to support students in completing lab assignments through virtualized computers. The project originated from research by Professor Patrick Seeling from Central Michigan University (CMU) and the need to support student’s interactions with virtual machines and delta files.

## 🧩 Project Overview

The Labs@Home application was created to:

* Provide students with a reliable, easy-to-use virtual environment for homework lab assignments.
* Automate complex tasks like managing QCOW2 delta files.
* Package virtual machine resources into a format that runs entirely on a student's flash drive or network share.
* Reduce setup friction for networking and computer science course homework at CMU.
